How AURA Works

AURA is not a simple recommendation widget. It is an agentic system that continuously observes your behavior, reasons over it, and generates personalized course recommendations.

The Agent Loop

01

Observe

Every meaningful action — page views, searches, clicks, time spent — is tracked in a non-blocking way and sent to the backend.

02

Understand

The LangGraph agent analyzes your recent behavior, extracts interests, skill level, and intent, then builds a living profile.

03

Retrieve

Relevant courses are retrieved from the vector store using Mesh embeddings and metadata filters grounded in the real catalog.

04

Evaluate

The agent scores candidate courses for relevance. If quality is low, it automatically broadens the search and tries again.

05

Generate

A persuasive narrative is written using a stronger model, explaining why these specific courses match your current journey.

06

Deliver

The recommendation is stored, shown on your dashboard, and can be refreshed as your behavior evolves.

Key Capabilities

Core
Behavioral Tracking
Non-blocking event batching with sendBeacon, viewability tracking, and time-on-page signals.
Core
Dual-Write Catalog
Every course is stored in SQLite and embedded into ChromaDB through Mesh API so recommendations stay grounded.
Agent
Self-Correcting Agent
LangGraph workflow with a conditional refetch loop that improves recommendation quality automatically.
Agent
Persuasive Messaging
Recommendations are not bare lists. They come with tailored narratives designed to motivate action.
Efficiency
Smart Triggers
The agent only runs when it should — cold start, high intent, search signals, staleness, or manual refresh.
Compliance
100% Mesh Native
All LLM reasoning and embeddings are routed through Mesh API. No direct provider calls.
